🍔 Safir Fast Food

A responsive food ordering web application developed for Safir Fast Food.

📌 About the Project

This project was developed as a real-world website for Safir Fast Food.

I was responsible for the front-end development and UI implementation, including the customer-facing interface and the management panel.

The project was designed with a focus on a clean, responsive, and user-friendly experience across different screen sizes.

👩🏻‍💻 My Role

Front-End Developer

• Designed and implemented the front-end interface
• Built responsive layouts
• Developed the food/menu sections
• Implemented the admin dashboard UI
• Created category and item management interfaces
• Added interactive functionality using JavaScript
• Connected the front-end structure to the project’s data flow

🛠️ Technologies

• HTML5
• CSS3
• JavaScript
• Responsive Web Design

📱 Features

• Responsive design
• Food/menu listing
• Category management
• Item management
• Admin dashboard
• Add, edit and delete items
• Enable/disable item status
• Enable/disable category status
• Popup forms for creating and editing content
